## About

Personal portfolio website built as a single self-contained HTML file.
Showcases my engineering background, work experience, certifications, and academic thesis.

---

## Tech Stack

- Pure HTML, CSS, Vanilla JavaScript — no frameworks
- Google Fonts (Syne + DM Sans)
- Hosted via GitHub Pages

## Features

- 🌍 EN / FR bilingual (language saved in localStorage + URL param)
- ✨ Particle canvas background + custom animated cursor
- 📱 Fully responsive (mobile + desktop)
- 📄 Downloadable CV
- 🎓 Linked certifications and diplomas (PDF)
- 📜 Master's thesis deep-dive section
